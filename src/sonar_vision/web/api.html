Contrato da API

API local do protótipo SONAR VISION. Consultar schema OpenAPI completo.

POST /api/sessions inicia uma sessão e retorna HTTP 202 com session_id.

{"route_requested":"971D-10","mode":"simulation","max_seconds":30}

Em modo real, informe source_url HTTPS direto em host autorizado pelo servidor. Exige pesos customizados.

  • GET /health: disponibilidade e versão.
  • GET /api/sessions/{id}: estado, eventos e desempenho da sessão.
  • DELETE /api/sessions/{id}: solicita cancelamento.
  • GET /api/sessions/{id}/frame: último JPEG; HTTP 204 enquanto não há frame.
  • GET /api/sessions/{id}/events: eventos v1, sem imagens.
  • GET /api/sessions/{id}/legacy: adaptação para o contrato do grupo.

Semântica

CONFIRMED exige pelo menos três frames e refere-se apenas ao código visual. MATCH indica igualdade com o código completo solicitado; NON_MATCH indica outra linha. UNCERTAIN impede anúncio positivo. Destino e tempo parado permanecem nulos.

Scores de detector e OCR são separados e não são probabilidades calibradas. Eventos artificiais carregam simulated=true e source=simulation.

422: entrada/fonte inválida; 503: pesos ausentes; 429: capacidade ocupada; 404: sessão expirada/inexistente; 413: payload acima de 16 KiB. Falhas posteriores de inicialização ou vídeo aparecem como estado ERROR da sessão.
